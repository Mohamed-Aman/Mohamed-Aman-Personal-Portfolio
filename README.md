# Mohamed Aman — Game Developer & Gameplay Programmer Portfolio

A clean, modern, high-performance portfolio website built for **Mohamed Aman**, a **B.Tech Computer Science graduate** specializing in **Unreal Engine 5, C++, and Real-Time Systems**, currently undergoing advanced game development training at **EXR School of Game Dev**.

---

## 🌟 Highlights & New Updates

- **Clean Dual-Theme Architecture**: Seamless toggle between a refined **Dark Mode** and a crisp, modern **Light Mode** with zero flash on load (`localStorage` + OS preference detection).
- **Featured Unreal Engine 5 Projects**:
  1. **Outbreak: Last Stand** *(Unreal Engine 5 — Solo In-Development)*:
     - Third-person tactical zombie survival with EQS horde pathfinding, deterministic C++ weapon ballistics, sound aggro propagation, and Lumen lighting.
  2. **High Tide** *(Unreal Engine — Game Jam Team Project)*:
     - Challenging 3D vertical maze platformer engineered under game jam constraints. Navigate perilous ruins, execute high-precision jumps, control your anger, and find the escape path to beat the game.
  3. **Street Heist: Endless Runner** *(Unreal Engine — Solo Featured Title)*:
     - Fast-paced 3-lane endless runner with procedural chunk pooling, obstacle avoidance, coin combo economy, and Niagara VFX.
- **Academic & Multi-Platform Games**:
  - **Block Stacking** *(Unity 2022 LTS / C#)*: Real-time dynamic mesh slicing and competitive split-screen physics stacker.
  - **UseCrayon.ai Web Titles**: *CLASHBORN* (3-life arena fighter), *Zombie Last Stand* (urban horde survival), and *Foxtrot Heist* (action pursuit runner).
- **Downloadable Resume / CV**: Direct printable resume built-in at `assets/docs/resume.html`.

## 🌐 Free 1-Minute Deployment Options

### Option A: GitHub Pages (Recommended)
1. Push this folder to your GitHub repository (e.g. `yourusername/portfolio`).
2. Go to **Settings** -> **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save** — your site is instantly live at `https://yourusername.github.io/portfolio/`!

### Option B: Netlify / Vercel
- Drag and drop the `Portfolio` folder directly onto [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com) for instant free HTTPS hosting.
